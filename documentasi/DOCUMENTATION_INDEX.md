## 🎓 Learning Paths

### Path 1: Pemula (Baru Mulai)

**Hari 1: Setup & Basics**
1. Baca **[README.md](README.md)** (10 menit)
2. Baca **[EMULATOR_QUICK_START.md](EMULATOR_QUICK_START.md)** (10 menit)
3. Install Firebase CLI
4. Start emulator: `npm run emulate`
5. Explore Emulator UI: http://localhost:4000

**Hari 2: Understanding Emulator**
1. Baca **[FIREBASE_EMULATOR_SUMMARY.md](FIREBASE_EMULATOR_SUMMARY.md)** (15 menit)
2. Baca **[EMULATOR_VS_PRODUCTION.md](EMULATOR_VS_PRODUCTION.md)** (15 menit)
3. Practice: Create, read, update, delete documents
4. Practice: View data in Emulator UI

**Hari 3: Testing Features**
1. Baca **[EMULATOR_TESTING_SCENARIOS.md](EMULATOR_TESTING_SCENARIOS.md)** (30 menit)
2. Practice: Test self-referral prevention
3. Practice: Test rate limiting
4. Practice: Test tier progression

**Hari 4: Advanced Features**
1. Baca **[PROFESSIONAL_FEATURES.md](PROFESSIONAL_FEATURES.md)** (20 menit)
2. Practice: Test commission holding period
3. Practice: Test payout priority
4. Practice: Test fraud detection

**Hari 5: Deploy**
1. Baca **[TECHNICAL_GUIDE.md](TECHNICAL_GUIDE.md)** (20 menit)
2. Run all tests in emulator
3. Deploy to production
4. Monitor production
