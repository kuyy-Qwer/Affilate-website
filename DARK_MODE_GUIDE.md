# 🌓 Panduan Dark Mode DigiSell

## Cara Menggunakan Dark Mode

Dark mode di DigiSell dapat **diaktifkan dan dinonaktifkan** kapan saja sesuai preferensi Anda.

### 🎯 Cara Mengaktifkan/Menonaktifkan

Ada **2 cara** untuk toggle dark mode:

#### 1️⃣ **Dari Header (Desktop)**
- Lihat di bagian kanan atas header
- Klik icon **🌙 Moon** untuk mengaktifkan mode gelap
- Klik icon **☀️ Sun** untuk kembali ke mode terang

#### 2️⃣ **Dari Sidebar**
- Scroll ke bagian bawah sidebar
- Klik tombol **"Mode Gelap"** atau **"Mode Terang"**
- Tombol memiliki toggle switch visual untuk kemudahan

---

## 🎨 Perbedaan Mode

### Mode Terang (Default)
- ✅ Background putih dan abu-abu terang
- ✅ Text hitam/abu-abu gelap
- ✅ Cocok untuk siang hari
- ✅ Lebih hemat baterai di layar LCD

### Mode Gelap
- ✅ Background hitam dan abu-abu gelap
- ✅ Text putih/abu-abu terang
- ✅ Cocok untuk malam hari
- ✅ Mengurangi kelelahan mata
- ✅ Lebih hemat baterai di layar OLED

---

## 💾 Penyimpanan Otomatis

- ✅ Pilihan mode Anda **tersimpan otomatis**
- ✅ Tidak perlu setting ulang setelah refresh
- ✅ Tersimpan di browser (localStorage)
- ✅ Berlaku untuk semua halaman dashboard

---

## 🎯 Fitur Dark Mode

### Yang Berubah:
- ✅ Background semua halaman
- ✅ Sidebar dan navigation
- ✅ Cards dan containers
- ✅ Text dan borders
- ✅ Buttons dan inputs
- ✅ Modals dan popups

### Yang Tetap:
- ✅ Logo dan branding
- ✅ Warna primary (hijau teal)
- ✅ Gradient effects
- ✅ Icons dan illustrations

---

## 🔧 Troubleshooting

### Mode tidak berubah?
1. Refresh halaman (F5)
2. Clear cache browser
3. Pastikan JavaScript enabled

### Mode kembali ke default?
- Cek apakah cookies/localStorage diblokir
- Pastikan tidak menggunakan mode incognito

### Warna tidak sesuai?
- Pastikan browser support CSS dark mode
- Update browser ke versi terbaru

---

## 💡 Tips

1. **Gunakan mode gelap di malam hari** untuk mengurangi kelelahan mata
2. **Gunakan mode terang di siang hari** untuk visibilitas lebih baik
3. **Toggle kapan saja** sesuai kondisi pencahayaan ruangan
4. **Pilihan tersimpan otomatis** - tidak perlu setting ulang
